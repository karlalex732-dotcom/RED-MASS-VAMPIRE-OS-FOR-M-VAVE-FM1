# RED MASS VAMPIRE OS v0.5.1-alpha — GitHub Release

For M-VAVE FM1, firmware identity **FM-1_906**.

## Highlights

- Six tracks: five instruments and drums on T6, with eight shared voices.
- 256 curated built-in presets (128 existing + 128 new), including eight piano
  variations. The editable user bank remains 32 slots.
- 32-row Song Mode for complete arrangements, with four project sources.
- Twelve new creative/performance functions, including macros, step locks,
  per-pad drum chance, microtiming, mute groups, sound mutation and undo/redo.
- NIGHT TRAP and RAGE TRAP drum kits, a redesigned red interface, and unified
  bold font. Track 5's selection frame is now fully visible on HOME.

## Updating and status

Back up projects before flashing. Keep the FM1 connected and powered until the
compatible `.fwsc` updater completes. This is an alpha build. The host test
suite and target build passed; physical FM1 install and timing were not
qualified in the recorded release validation. See `docs/RED-MASS-English-Guide.md`
and `BUILDING.md` in the repository.
