START
1. Extract the entire ZIP.
2. Double-click RED-MASS-VAMPIRE-OS.exe.
3. Open Install / recover, connect the powered FM-1, allow USB-MIDI/SysEx, save a complete backup, then click Install.
4. Keep power/USB connected until FM-1_906 is verified.
5. Open Full editor for all sound, sequencer, mixer, Song Mode, library, sample, project, backup and settings functions.

Python is NOT required. The native x64 Windows EXE uses installed Microsoft Edge or Google Chrome in application-window mode. It opens the correct pages and starts a loopback server automatically. No manual server commands, Node or .NET runtime installation.
Keep the EXE next to web-tools, firmware, docs, source and the other folders. Right-click the RED MASS tray icon to reopen or exit the app after any update has finished.

FIRMWARE
T1–T5: instruments. T6: drums. Eight voices shared across six tracks.
256 curated ROM presets, including eight sampled pianos; 32 editable user slots.
32-row Song Mode with four saved-project sources, 64 steps per track and the twelve performance tools.
Two built-in sample kits: NIGHT TRAP (replaces old factory kit) and RAGE TRAP (separate factory kit). USER KIT 1–3 retain their indices and data.
Uniform Inter Tight Bold (700) across original pages and added tools.
Legacy four-track projects migrate their T4 drums and associated feature data to T6.
