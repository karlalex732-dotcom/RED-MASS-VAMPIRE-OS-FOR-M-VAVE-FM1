# Contributing to RED MASS VAMPIRE OS

Thanks for helping! To keep things easy to follow, please use the right place:

| What | Where |
|---|---|
| A bug you can reproduce | [Issues](../source/README.md/issues/new/choose): one issue per bug |
| A feature idea or request | [Discussions › Ideas](../source/README.md/discussions/categories/ideas) (no promise it will be added) |
| How to use it, or how something works | [Discussions › Q&A](../source/README.md/discussions/categories/q-a) |
| Forks, mods, music, demos | [Discussions › Show and tell](../source/README.md/discussions/categories/show-and-tell) |
| Anything else | [Discussions › General](../source/README.md/discussions/categories/general) |

Feature requests posted as issues will be moved to Discussions or closed.

## Reporting a bug

Please include the RED MASS VAMPIRE OS version (hold HOME > ABOUT), your computer's OS and browser if the editor or
installer is involved, the steps to reproduce it, what you expected and what happened. A photo or a short
video helps.

## Pull requests

Pull requests are welcome, including AI-assisted ones, with the same bar for all:

- keep it small and focused on one thing;
- make sure you understand the change and can explain it;
- test it on a real FM-1;
- run `tests/run_tests.sh` (see [BUILDING.md](BUILDING.md));
- new files carry the GPL-3.0-only SPDX header.

By contributing you agree that your contribution is licensed under GPL-3.0-only.

The web editor and installer live in [RED-MASS-WebApp](../source/README.md-WebApp).
