# Проверка RED MASS v0.5.2-beta / Darker bank

Проверялся настоящий C-код прошивки с host HAL и целевая сборка Jieli pi32v2. Физический FM1 и запуск Windows-приложения на Windows в этой сессии не проверялись.

## Объём изменения

Изменены 216 рецептов встроенных пресетов. Номера, имена, engine/factory IDs и ограничения полифонии всех 256 записей прежние. Полные 40 записей басов/808/перкуссии, включая FM6-патчи и параметры редактора, совпадают с исходной v0.5.1. Генераторы PCM, исходники DSP, проекты, MIDI, секвенсор, UI и обоих drum kit не менялись. В приложении обновлены версия и описание банка.

## Рендеры и защита неизменённых звуков

Каждый из 256 звуков обеих версий отрендерен отдельным native-процессом. Такой запуск исключает влияние истории генератора случайного возбуждения PHYS и эффекта предыдущего пресета. По одному 12-секундному WAV на звук, с проверкой голосов до 24 секунд.

- 40 защищённых WAV совпадают **побайтно**. Сравнение полного JSON этих пресетов также прошло.
- Остальные 216 имеют изменённые исходные параметры и отличный от прежнего PCM.
- В новом банке **256 различных PCM-хэшей**.
- Нет выхода за int16, зависших голосов или превышения доступной полифонии. Максимальный peak среди отдельных примеров — 19288.
- У 195 из 216 изменённых звуков ниже спектральный центроид; медианное отношение нового к старому около 0,64. Анализ: stereo power, 0,15–2,95 секунды удержания. Это описательная характеристика спектра, не числовая оценка настроения.
- Генерируемые `groove_kit.h`, `vampire_pcm.h`, `red_mass_samples.h` совпадают с исходной версией. Две последовательные native-демонстрации NIGHT TRAP / RAGE TRAP со всеми 32 пэдами также совпали побайтно.

Данные — `audit.json`, `comparison.csv`, `isolated-health.json`. Дополнительного EQ, нормализации или мастеринга в проверочных WAV нет. В A/B-монтаже только нарезка, короткие краевые fades, разделяющая тишина и MP3-кодирование.

## Автоматические проверки

Выполнен полный `tests/run_tests.sh`. Он обнаружил постоянную составляющую в двух новых LFSR-шумовых тембрах. Частота возбуждения этих двух пресетов была исправлена; после исправления отдельно повторены профильные проверки. Исходный журнал полного прогона сохранён, включая найденную ошибку; итоговая проверка NOISE находится в `noise-final.log`.

Итог:

- NOISE: все тесты прошли. DC-проверка по 16 нотам/seed на пресет — worst 0,94% при исходном пороге <1%; clipping, key tracking, периодичность и повторяемость прошли.
- 418 регрессионных рендеров: 0 отличий от итоговых эталонов, 0 health failures, 0 voice/routing failures, 0 crashes. От v0.5.1 изменены ровно 216 ожидаемых engine/slot-пар; остальные 202 сценария прежние.
- Обновлены только эти 216 аудиоэталонов. CPU, target, DC, peak, tail и memory budgets не ослаблялись.
- Нативные Trap/Club loader, полные значения, FM6, project и пользовательские звуки проверены.
- UI/шрифты/layout, legacy FM4, Song Mode, 12 tools, сохранение и миграции, MIDI, USB, loader, backup, модуляция, эффекты и модели DSP прошли в полном прогоне; правки касаются данных пресетов.
- Импорт всех 256 JSON-записей и восьми 32-slot банков, web protocol, full backup и native groove reply проверены повторно после финального экспорта.
- Пакет updater проверен на симулированном устройстве. Контроллер приложения, освобождение MIDI-портов и Win32 HTTP/path logic проверены с инструментированным host-окружением; это не замена Windows/hardware qualification.
- Статические pi32v2 render-loop budgets прошли.

Отдельное сравнение с float DaisySP пропущено: отсутствует checkout. WASM/browser emulator не собирался: нет Emscripten. Аппаратный счётчик инструкций `proc_pid_rusage` недоступен на этом Linux; host-время не выдаётся за нагрузку FM1.

## Целевая сборка

Toolchain: `jieli-linux-toolchains-20260730.1`, полученный штатным `tools/get_toolchain.sh` URL. Три неизменённых SDK-файла извлечены из предоставленного пакета v0.5.1 и проверены по закреплённым SHA-256.

- Package identity: **FM-1_907**, 609856 байт.
- App image: 574084 байта.
- RAM `.data + .bss`: 92720 / 94208 байт.
- Pool: 330944 / 339968 байт.
- Aux SRAM: 27716 / 28416 байт; boot-status area исключена штатным linker layout.
- `.ram_text`: 916 инструкций, внешних вызовов нет.
- Регистры: доступ только через HAL.

Все стандартные ограничения памяти сборщика сохранены и пройдены. Детали и фактический SHA-256 прошивки находятся в `build-0.5.2.log` и корневом `SHA256SUMS.txt`. ZIP проверен по CRC; установщик и прошивка используют один и тот же файл пакета.

Windows launcher взят неизменённым из предыдущего комплекта; обновлены локальные страницы, банк и выбранная прошивка. GPL-3.0 исходники, сторонние лицензии и v0.5.1 для отката включены.

## Выпуск beta

v0.5.2-beta — переименование той же звуковой сборки. Версия пересобрана в бинарном файле, установщике и метаданных банка. Параметры всех 256 пресетов и сгенерированные аудиотаблицы проверены на совпадение с v0.5.2-alpha; DSP и проекты не менялись. Целевая сборка и проверки пакета повторены. Прежние журналы native audio относятся к тем же неизменённым данным. Статус beta не означает завершённую физическую квалификацию FM1.
