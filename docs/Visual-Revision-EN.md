# Visual revision 2 — RED MASS VAMPIRE OS v0.5.1-alpha

The HOME track rail has been respaced so the selection frame for track 5 is fully visible. Tracks 1–6 remain selectable and their frames fit within the display regions.

Factory and user preset names use the same 15 px bold face on HOME and in the preset lists, regardless of name length or whether they belong to the original or new sound bank. Engine tags, pattern numbers and the narrow mixer labels remain compact to fit their controls.

The ZIP includes native firmware captures of the HOME view with track 5 selected and both generations of sounds in HOME and the preset browser. The host renderer checks all six HOME frames and compares the displayed name height between both banks. The general UI lint and alignment suite was rerun across all screens and palettes.

This revision retains package identity **FM-1_906** and the six-track song, audio and storage behavior. To install it over the preceding v0.5.1-alpha, extract the new ZIP to a separate folder, open the included Windows installer, make a complete backup, then use **Install**. The installer permits reinstalling the same identity.
