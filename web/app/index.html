The complete editor

Sound parameters, envelopes, LFOs, modulation matrix, FM6 patch editing, effects, step sequencer, drum grid, six-track mixer, Song Mode, motion, samples, preset library, saved projects, complete backups and device settings.

Connect. Back up. Install.

Connect the powered FM-1 with a USB data cable. Close DAWs and other MIDI tabs, allow MIDI/SysEx access when prompted, and save your music before updating. The installer verifies the package and the device identity after restart.

NIGHT TRAP + RAGE TRAP

Two distinct original 16-pad kits: deep sustained 808s, punchy kicks, snappy snares, layered claps, crisp hats and tuned percussion. Both are built into the firmware and play on track 6.

One bold visual system

Red, black, pink, grey and white. Firmware labels and values now use the same bold font weight across the original screens and the performance tools.

Alpha release. Host checks and build checks are documented in the package. Physical FM-1 and Windows runtime qualification are pending. Six tracks share eight sounding voices; there are 32 editable device preset slots.
